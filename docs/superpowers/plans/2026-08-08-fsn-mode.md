# fsn Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recreate the original SGI fsn (IRIX 3D File System Navigator) look and interaction inside our macOS/Metal fsv port — landscape sky/ground, pedestals connected by navigable wires, 7-bucket age colors with legend, flight navigation, selection spotlight, overview window — as a fourth visualization mode plus mode-aware UI, on branch `fsn-mode`.

**Architecture:** Everything is ADDITIVE to the metal-port codebase. A new `FSV_FSN` member joins the `FsvMode` enum (src/common.h:127); geometry gets fsn layout/draw functions alongside the discv/mapv/treev families; camera gets an fsn arm in its per-mode switches plus one new flight entry point; the renderer gets a sky/ground pass and a spotlight decal; the UI gets a control rail, an ages legend, and (Milestone C) a picture-in-picture overview. The GTK arm must keep compiling — new geometry goes through the existing `gpu.h` contract which ogl-gpu-compat.c already implements; GTK just won't expose the new mode in its menus (SDL-only mode registration is acceptable and documented).

**Tech Stack:** Existing stack unchanged (C core, C++20 SDL frontend, SDL_GPU/Metal, Dear ImGui, GLib, cglm, Meson). No new dependencies.

## Current-state anchors (verified 2026-08-08)

- `FsvMode` enum: src/common.h:127. Mode dispatch: `geometry_init(FsvMode)` / `geometry_draw(boolean)` (src/geometry.h:90-91) with per-mode static families in geometry.c (`discv_*`, `mapv_*`, `treev_*`).
- Dormant camera API (exists, unwired in SDL UI): `camera_look_at_previous()` (camera.h:90), `camera_birdseye_view(boolean)` (camera.h:91), `camera_scrollbar_moved(int axis)` + `fsv_platform.set_scroll/get_scroll` (Tilt/Height analogs).
- Color engine: `SPECTRUM_RAINBOW/HEAT/GRADIENT/NONE` (src/color.h:36-39), continuous `by_timestamp` mapping in color.c; persistence via nvstore (`~/.fsvrc`).
- Renderer: single scene pass, clear color `{0.08,0.10,0.12,1}` (src/sdl/gpu.cpp `gpu_scene_end` clear); topologies incl. `FSV_LINES` (src/gpu.h:60-65); offscreen capture + pick infra exist.
- Gestures: src/sdl/input.cpp (middle-drag dolly, Ctrl+left revolve, wheel, double-click expand, Esc); per-mode branching precedent exists in camera.c, not yet in input.cpp.
